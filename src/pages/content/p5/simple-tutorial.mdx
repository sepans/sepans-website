### دستگاه مختصات

برای کشیدن شکلها باید جای اون ها رو تو صفحه مشخص کنیم. برای این کار از دستگاه مختصات استفاده میکنیم.

 گوشه بالا سمت چپ صفحه نقطه (0, 0) است و هرچی به سمت چپ بریم مقدار x و هرچه به پایین بریم مقدار y بیشتر میشه.


<CenteredContainer>
    <CodeEmbed
            client:load
            showCode={false}
            previewWidth={200}
            previewHeight={200}
            initialValue={`
                function setup() {
                    createCanvas(200, 200)  
                }

                function draw() {   

                background('white')
                for(let i = 0; i < 400; i = i + 10) {
                    stroke('#B5B5B5')
                    strokeWeight(1)
                    line(i, 0, i, width);
                    line(0, i, height, i);
                }
                fill('black')
                stroke('black')

                circle(1, 1, 7)
                noStroke()
                text('(0, 0)', 5, 15);

                circle(mouseX, mouseY, 7)
                strokeWeight(1.5)
                stroke('black')
                const xPos = mouseX || 120
                const yPos = mouseY || 50
                line(0, yPos, xPos, yPos);
                line(xPos, 0, xPos, yPos);
                strokeWeight(1)
                if(xPos > 0 || yPos > 0) {
                    noStroke()
                    text('x', xPos + 5 , yPos / 2);
                    text('y', xPos / 2 , yPos + 10);
                    text('('+xPos+','+yPos+')', xPos + 5, yPos);
                }
            }
        
            `}
            previewable
            editable={true}
            lazyLoad={false}
            allowSideBySide={true}
            includeSound={false}
        />

</CenteredContainer>

### دستورهای به درد بخور

#### تغییر رنگ زمینه

<code>background(‘white’)</code>

می‌تونید روی رنگ کلیک کنید و یه زنگ جدید انتخاب کنید. یه چیزی شبیه این میشه

<code>background('#FF0000')</code>

این کد رنگ قرمز ه. p5.js رنگها رو به هم با کد میشناسه هم با اسم مثل 'red' یا 'pink' 

<Paragraph type="warning">
حواستون باشه رنگ یا کد رنگ باید بین دو تا  <code>'</code>  باشه. کد رنگ همیشه با  <code>#</code>  شروع میشه.
</Paragraph>
