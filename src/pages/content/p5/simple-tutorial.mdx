#### متغیرها

متغیر مثل یه جعبه ای ه که میشه توش یه عدد (یا متن) گذاشت و از اون استفاده کرد. متغیرها کمک میکنه که یه سری اعداد را لازم نباشه تکرار کنیم. مثلا اینجا 

<code>
rect(5, 10, <b>10</b>, <b>10</b>)<br/>
rect(15, 30, <b>10</b>, <b>10</b>)
</code>

اندازه مربع های ما ۱۰ هست. پس میتونیم یه متغیر تعریف کنیم به اسم size و از اون استفاده کنیم

<code>
<b>var size = 10</b><br/>
rect(5, 10, <b>size</b>, <b>size</b>)<br/>
rect(15, 30, <b>size</b>, <b>size</b>)
</code>

مثلا توی مثال قبل میشه نقطه‌ای که کله آقا هست رو توی دوتا متغیر <code>headX, headY</code> گذاشت تا بشه به راحتی جای کله رو عوض کرد. امتحان کنید:

<code>

</code>

اینجا یه متغیر به اسم  <code>i</code>  تعریف کردیم که اول 0 ه.

<code>
for(var i = 0; i < 130;<b> i = i + 40 </b>)
</code>

هر دفعه که حلقه اجرا می‌شه 40 تا به <code>i</code> اضافه میکنیم.

<code>
for(var i = 0;<b> i < 130;</b> i = i + 40)
</code>

تا وقتی که  <code>i</code> کوچکتر از ۱۳۰ باشه.

#### random
دستور random یه عدد شانسی به شما می‌ده. می‌شه به دستور random گفت که این عدد حداقل و حداکثر چقدر باشه. مثلا
<code>
random(0, 10)
</code>

یه عدد شانسی بین ۰ تا ۱۰ میده. 

یه کاربرد random کشیدن یه تعداد زیاد شکل جاهای مختلف صفحه با استفاده از حلقه است:

 <CodeEmbed

    اینجا از این متغیرها استفاده می‌کنیم که یه عدد شانسی برای <code>x</code> و <code>y</code> جایی که ستاره‌ها رو می‌کشه استفاده کنه.

   آیا می‌تونید کاری کنید که سایز ستاره‌ها هم متفاوت باشه؟ <b>راهنمایی:</b> از دستور <code>textSize</code>  همراه با <code>random</code> استفاده کنید.
    </Paragraph>

### قسمت‌های برنامه p5

تا حالا هرچی دستور استفاده کردیم داخل کروشه‌های <code>setup</code> بود و به <code>draw</code> کاری نداشتیم.
فرق <code>draw</code> و <code>setup</code> اینه که هر دستوری توی <code>setup</code> باشه فقط یکبار وقتی برنامه اول اول اجرا می‌شه انجام می‌شه ولی دستور های توی <code>draw</code> چندین بار در ثانیه همه شون پشت سر هم اجرا می‌شوند. این به چه دردی می‌خوره؟ تو قسمت بعد می بینیم که با این کار میتونیم شکل‌ها رو حرکت بدیم!

مثلا مثال ستاره‌های بالا اگه دستورها رو از توی <code>setup</code> ببریم توی <code>draw</code> اینجوری میشه:

    createCanvas(300, 200) 
}

function draw() {

       text('⭐', random(0, width), random(0, height))

چون برعکس مثال قبلی هر ثانیه چندید بار ستاره‌ها یک جای شانسی کشیده می‌شه و هر دفعه یه جای جدیده.

<Paragraph type="warning">
یک سری دستورها که برای تنظیمات اولیه است باید حتما توی <code>setup</code> باشه. مثل <code>createCanvas</code> که سایز صفحه رو تنظیم می‌کنه.
</Paragraph>

<Paragraph type="excercise">
   میتونید کاری کنید که ستاره‌ها روی هم بیاد تا تمام صفحه رو بگیره؟
   <b>راهنمایی: </b> چه چیزی باعث میشه هر بار صفحه پاک می‌شه؟ اگر اون دستور بره توی <code>setup</code> دیگه همه ستاره‌ها پاک نمیشه.
</Paragraph>
